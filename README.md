# Photo2

A modern macOS SwiftUI application for browsing, organizing, and previewing video files with thumbnail support.

The code is largely generated by claude-opus 4.5 model and tested and reviewed manually to ensure the quality.

## Features

### Video Thumbnail Browser
- **Grid-based thumbnail view** - Automatically generates and displays thumbnails for MP4 video files in a responsive grid layout
- **Smart thumbnail caching** - Thumbnails are generated once and cached, with automatic regeneration when files are modified
- **Adaptive grid layout** - Columns adjust automatically based on window width

### Video Preview
- **Hover-to-preview** - Enable the "Enable Preview" checkbox to start video preview after hovering over a thumbnail for 10 seconds
- **Embedded video player** - Full-featured video player with:
  - Play/Pause controls
  - Scrubber bar for seeking
  - Mute/Unmute toggle
  - Auto-loop playback
- **Auto-dismiss** - Inactive video players are automatically dismissed after 1 minute of being paused

### Organization Features
- **Like/Favorite system** - Command+click on any thumbnail to mark/unmark as liked (highlighted with yellow border)
- **Multiple sorting options**:
  - A-Z / Z-A by filename
  - Oldest / Newest by modification date
  - Recently played videos
- **Liked-only filter** - Show only your liked videos
- **Search filter** - Search by filename with:
  - Automatic wildcard matching (searches contain pattern by default)
  - Space-separated terms for multiple wildcards
  - Case-insensitive search
  - Visual validation (red border for invalid characters)

### File Management
- **List not-liked files** - Generate a text file listing all unliked videos with file sizes, sorted by size (largest first)
- **Save/Load collections** - Save your organization (thumbnails, likes, play history) to YAML+data files
- **Recent files menu** - Quick access to up to 5 recently used save files
- **Auto-save prompt** - Warns before quitting if there are unsaved changes

### Status Bar
- Displays current count of shown files and total files

## Technical Highlights

### Performance Optimizations
- **Regex caching** - Search patterns are compiled once and cached for repeated use
- **O(1) URL lookups** - URL-to-index dictionary for fast asset lookups during thumbnail generation
- **Lazy grid rendering** - Uses `LazyVGrid` for efficient memory usage with large collections

### Swift 6 Compatibility
- `Sendable` conformance for cross-actor data safety
- `@MainActor` isolation for UI-related state managers
- Modern async/await patterns for file operations

### Architecture
- **AppStateManager** - Singleton for app-wide state (modification tracking)
- **VideoPlayerStateManager** - Manages multiple video player instances with auto-dismiss functionality
- **VideoPlayerManager** - Handles AVPlayer lifecycle and controls
- **RegexCache** - Thread-safe singleton for caching compiled regular expressions

## Requirements

- macOS (built with SwiftUI)
- Xcode 15+ (for Swift 6 features)

## Dependencies

- [Yams](https://github.com/jpsim/Yams) - YAML encoding/decoding for save files
- QuickLookThumbnailing - System framework for thumbnail generation
- AVKit - Video playback

## Usage

1. **Select Video Folder** - Choose a folder containing MP4 files
2. **Browse** - View thumbnails in the grid
3. **Organize** - Use Command+click to like videos, use sorting/filtering options
4. **Preview** - Enable preview checkbox and hover over thumbnails to watch videos
5. **Save** - Save your collection (Cmd+S) to preserve likes and play history
6. **Load** - Load previously saved collections from the recent files menu

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd+S` | Save File |
| `Cmd+Click` | Toggle Like |
| `Double-Click` | Open video in default player |
